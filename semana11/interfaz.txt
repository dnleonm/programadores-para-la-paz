La plataforma tendría una interfaz sencilla y fácil de utilizar. En la parte principal habría un formulario para crear una nueva solicitud o causa comunitaria con campos como título, descripción y fecha. También existiría una lista donde se mostrarían las solicitudes registradas para que los usuarios puedan consultarlas. Cada solicitud tendría un botón para apoyar la iniciativa y un contador que indique el número de apoyos recibidos. La interfaz evitaría mostrar información privada de los usuarios y presentaría únicamente los datos necesarios para la participación ciudadana.
