Durante este curso aprendí que la tecnología puede convertirse en una herramienta muy poderosa para fortalecer la participación ciudadana cuando se desarrolla pensando en las necesidades reales de la comunidad. El proyecto "Petición en 3 Clics" me permitió comprender cómo integrar un backend, una base de datos, una interfaz web y la generación de documentos para construir una solución útil y organizada. También entendí la importancia de proteger la información personal, recolectando únicamente los datos necesarios y promoviendo buenas prácticas de privacidad. Otro aprendizaje muy valioso fue el uso de Git y GitHub para llevar un control de versiones y facilitar el trabajo organizado durante el desarrollo del proyecto. Además, conocí herramientas como Express, SQLite, PDFKit, n8n y Telegram, que permiten automatizar procesos y mejorar la comunicación entre las personas. Finalmente, comprendí que desarrollar software con impacto social implica actuar con responsabilidad, trabajar de forma colaborativa y crear soluciones que contribuyan al fortalecimiento de la participación democrática y la organización comunitaria.
